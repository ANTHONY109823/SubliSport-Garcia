1. Resumen ejecutivo

SubliSport García es un sistema de gestión interno para una empresa de confección deportiva sublimada. Combina:

  • Panel administrativo — Blazor Server (.NET 10) con login por roles.
  • Sitio público estático — index.html (landing) y cotizar.html (formulario de cotización).
  • API REST — Endpoints mínimos para cotizaciones web y configuración.
  • PostgreSQL — Persistencia en Railway.

Usuarios principales: Wilber (Admin), diseñadores, Juanita (Producción), clientes vía web.

8. Sitio público (landing)

index.html

Landing marketing: hero, servicios, galería, contacto. Tema oscuro dorado (#F0A500). Enlaza a cotizar.html y login del panel.

cotizar.html + landing-config.js

  • Selector tipo cliente: Directo retail vs Servicio MYPE B2B.
  • Tipo prenda: Conjunto, Camiseta, Mixto (chips).
  • Tela, bordado (logo/marca/short círculos), cantidad, fecha entrega.
  • Lista jugadores: nombre, talla, número, género, prenda (conjunto/camiseta).
  • Import Excel/CSV, hasta 3 fotos referencia (base64 comprimido).
  • Envío: POST a /api/landing-quote + opción WhatsApp con texto generado.

Config cargada desde /api/landing-config o fallback en DEFAULTS del JS.

11. Motor de cotización web

Archivos: LandingQuoteCalculator.cs, LandingQuoteOrderAssembler.cs, LandingQuoteSubmit.cs

  • Tablas precio conjunto/camiseta por tier de talla y tela (dry_fit, etc.).
  • Bordados: logo, marca, short (unidades fijas por pieza).
  • Con roster: precio por fila según kitType (conjunto vs camiseta).
  • Genera: AdminSuggestionText, ClientProformaDraft, ClientRequestText (WhatsApp).
  • OrderAssembler persiste pedido y serializa roster a ConfectionRosterDetails.

14. Servicios (13) y Helpers (26)

Servicios principales

  • OrderService — CRUD pedidos, transiciones estado, asignación diseñador, proforma landing.
  • MetricsService — Dashboard admin/diseñador, leaderboard.
  • LandingConfigurationService — Config JSON cotizar.
  • PricingConfigurationService / PricingCalculatorService — Tarifas MYPE y calculadora metraje.
  • ProductionConfigurationService — Reglas producción.
  • QuoteReferenceImageService — Guarda fotos en wwwroot/uploads/quotes/.
  • UserManagementService / AuthService — Usuarios e impersonación.

Helpers destacados

  • DesignerOrderHelper, ProduccionOrderHelper — Lógica por rol.
  • OrderJourneyHelper, OrderDisplayHelper, OrderStatusHelper — UI y timeline.
  • LandingQuoteNotesHelper — Detecta cotizaciones web en PricingNotes.
  • ProformaDocumentBuilder, OrderProformaBuilder — Documentos imprimibles.
  • WhatsAppHelper — Links wa.me con mensajes.
  • GarmentTypeHelper, MixedGarmentHelper — Prendas mixtas.

18. Flujo típico end-to-end

Cliente → cotizar.html → POST /api/landing-quote → LandingQuoteCalculator + OrderService.CreateManualOrder → Order (CotizacionRecibida) + fotos en uploads/ Admin → /pedidos/nuevo o revisa web → asigna diseñador → Designer acepta → EnDiseno → aprobación cliente → DisenoAprobado → Producción (impresión/planchado/confección) → ListoEntrega → Entregado PDF confección: /produccion/{id}/ficha-confeccion (roster + corte + prenda)
